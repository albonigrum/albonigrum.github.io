Boardgames Bot Drive

I keep a board game library in Notion so it is easier to choose a game for the evening. My Telegram bot helps me add game cards to the library and pick a random game.

When I add a game, the bot can save a photo for its post in a Google Drive folder that I choose. It uses the file names in that folder to give each new photo a unique name.

The Google connection is used only for this photo workflow. Access can be revoked in my Google account settings.
